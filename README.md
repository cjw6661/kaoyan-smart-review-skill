# 考研专业课智能复习skill

这是一个面向 Codex 的考研专业课智能复习 Skill，用于把目标院校的考纲、真题、本科卷、本校 PPT、课堂讲义和参考书，整理成一套真正贴合该校考试风格的复习资料。

它不是通用课程笔记，也不会用其他学校的题型替代目标院校要求。Skill 会先审计官方资料和历年题目，再按照目标院校的满分、时间、题型和计算器规则生成知识点总结、单元测试、单元套题、模拟题、答案与评分细则，并自动检查总分、题号、答案和禁用题型。

## 主要能力

- 根据目标院校、专业课代码和资料目录建立考情清单
- 优先使用官方考纲、目标院校真题、本科卷和本校 PPT
- 区分官方题目、教材改编、辅助教材补充和预测扩展
- 生成知识点总结、公式表和高频简答
- 生成无选择题的单元知识点测试
- 生成单元套题和完整模拟卷
- 自动匹配 150 分或其他官方满分
- 自动校验填空题、简答题、综合计算题的数量和分值
- 检查答案缺失、题号重复、选择题残留、乱码和排版异常
- 支持 DOCX、PDF、PPTX 和图片资料的盘点与提取

## 默认出题规则

当目标院校没有公开明确题型时，Skill 默认采用：

```text
一、基础知识简答或填空：50 分
二、综合分析与计算：100 分
总分：150 分
```

单元知识点测试默认采用：

```text
一、填空题：10 题 × 5 分 = 50 分
二、简答与计算：10 题 × 10 分 = 100 分
总分：150 分
```

除非目标院校官方试卷明确要求，默认不生成单项选择题和独立判断题。适合记忆的选择题知识点会转换为填空题或简答题。

## 安装

下载仓库中的 `kaoyan-professional-course.zip`，解压后把 `kaoyan-professional-course` 文件夹放入：

```text
C:\Users\<用户名>\.codex\skills\
```

重新打开 Codex 对话后，可以使用：

```text
使用 $kaoyan-professional-course
```

## 包含内容

- `SKILL.md`：Skill 主入口和完整工作流
- `references/`：资料证据、试卷蓝图、出题规则、排版验收规则
- `scripts/`：项目初始化、资料盘点、蓝图校验、资料包审计脚本
- `assets/`：项目清单和试卷蓝图 JSON 模板
- `agents/openai.yaml`：Codex 界面元数据

## 使用原则

1. 目标院校资料优先于通用教材。
2. 官方真题和本科卷决定题型与问法。
3. 主教材决定定义、公式和章节顺序。
4. 辅助教材用于补充推导、例题和计算。
5. 预测题必须标注为预测扩展，不冒充真题。
6. 生成的每套试卷必须校验总分和答案完整性。
